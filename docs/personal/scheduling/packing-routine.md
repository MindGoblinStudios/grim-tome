# Packing Routine

An example of an event-triggered routine: it doesn't run on a schedule, it runs when life triggers it (a trip). It ships pre-filled so you can see what a finished routine doc looks like — edit it into your own.

### Purpose
Standard reusable packing list for personal and work trips. Baseline first, then adjust for weather, events, and transit.

### Use Order
1. Check destination weather and event notes.
2. Pick the luggage shape: suitcase, backpack/personal item, or both.
3. Pack travel/admin always-needed items first.
4. Pack electronics and chargers.
5. Pack clothes based on weather and event formality.
6. Pack toiletries and personal care.
7. Add comfort and travel-day items.
8. Final morning sweep for items that can't be packed early.

### Always-Pack Travel Admin
- ID (passport when relevant)
- Wallet / cards
- Phone
- Keys
- Meds and supplements
- Hotel confirmation checked
- Flight / transit details checked

### Backpack / Personal Item
- Laptop + charger
- Phone charger and cables
- Battery pack
- Headphones (noise-canceling for the plane)
- Water bottle, empty before security
- Notebook and pen
- Chapstick, kleenex
- Protein snack
- Sleep mask

### Clothes
- Travel outfit
- Underwear and socks: one per day plus one spare
- Shirts: enough for the trip, adjusted for weather and events
- Pants: one to two pairs for short trips
- Hoodie or light layer (plane, hotel AC, cool evenings)
- Sleep clothes
- Comfortable walking shoes
- Movement clothes if desired
- One nicer outfit or layer for dinners or events

### Toiletries & Care
- Toothbrush and toothpaste
- Deodorant
- Skincare
- Hair products / comb
- Razor if needed
- Sunscreen

### Final Morning Sweep
- Phone, wallet, keys, ID
- Laptop and chargers
- Headphones
- Meds
- Water bottle
- Toiletries used that morning
- Packed bag by the door

### Agent Notes (active packing)
When the user is actively packing, respond with one full nested checklist every time, not just the changed items. Mix done and open items in place with status emojis (✅ / ⬜), bubble status up to parent categories, and translate "outfits" into specific garment counts per day so items can be grabbed without decoding.
