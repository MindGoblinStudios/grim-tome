# Restaurant Directory

Places you actually go, with what to order. For nights the kitchen is closed.

## Directory Fields

Track enough detail to make the next decision easy. Do not estimate every dish on every menu.

| Field | What to record |
| --- | --- |
| Name | Restaurant name |
| Area | Neighborhood or landmark, not a private address |
| Access | Walk, drive, delivery, or some combination |
| Time | Approximate walk, drive, or delivery time |
| Hours | Useful weekly summary, especially closing time |
| Diet Fit | High-protein, lighter, vegetable-forward, comfort meal, treat, etc. |
| Default Order | One or two reliable orders |
| Rough Macros | A range only when it helps planning |
| Cost | Rough price band |
| Source | Official menu/site when possible |
| Last Checked | Date hours or menu were verified |
| Notes | Wait risk, pickup friction, seating, delivery quality, preferences |

## Update Rules

- Verify hours before relying on a narrow closing window.
- Record a reliable order after a good meal; record a warning after a bad one.
- Use ranges for restaurant macros unless the restaurant publishes nutrition.
- Keep private addresses out of restaurant rows. Use neighborhood-scale anchors.
