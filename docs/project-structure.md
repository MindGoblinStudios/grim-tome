# Project Structure

Short map of what lives where. Agents read this first to route reads and writebacks. Keep it current as docs grow.

### Folder Layout
- `ops/` — standard operating procedures & tribal knowledge
- `computerUseAppInstructions/` — how to operate local apps, one doc per app
- `browserUseInstructions/` — how to operate websites, one doc per site
- `biz/` — business info & goals
- `finance/` — finance plans
- `personal/scheduling/` — routine, todos, fixed anchors, packing routine (filled example)
- `personal/health/` — meal playbook, active meal plan, restaurants
- `personal/food-inventory/` — groceries, pantry, fridge, freezer, spices, equipment
- `personal/recipes/` — recipe index
- `personal/workout/` — workout rules, active program, lift history
- `../memory/` — durable cross-session memory (`MEMORY.md`)
