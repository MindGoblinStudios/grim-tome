# Skill Stat Cards

Every skill in the Tome's README carries a small stat card:

| Difficulty     | 🟩🟩⬜ Medium     |
| -------------- | -------------- |
| **Invocation** | **⚡ Auto**       |
| **Requires**   | **An API key** |

**Difficulty** — how hard it is to pick up:

🟦⬜⬜ Easy — brand new to vibe coding. No coding needed, just talk.  
🟩🟩⬜ Medium — you've touched AI tools a bit and want to go deeper.  
🟪🟪🟪 Pro — you're in it. You're spending the tokens. Rip it.

**Invocation** — `Auto` means your agent can reach for the skill itself when it fits; `Manual` means it only runs when you call it by name (`/grim:...`).

**Requires** — only shown when a skill depends on something you might not have: an API key, a paid service, or a capability you can't just install.

Under each card there's a folding **Examples** section with three ways to cast the skill — plain, with a follow-up prompt, mid-sentence, or comboed with other skills.

Start with the Easy ones and work up. The install (`/grim:terface:install`) asks your familiarity first and calibrates everything to it.
